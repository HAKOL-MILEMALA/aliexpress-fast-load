# אליאקספרס - כפתור טעינה מהירה (Tampermonkey)

סקריפט המשפר את ממשק השותפים (Affiliate) באתר AliExpress. הסקריפט מוסיף כפתור "⚡ טען" ייעודי לצד הכפתור המקורי, שמייצר את קישור ההפניה ומעביר אליו אוטומטית ובמהירות, תוך הסתרת החלון הקופץ ברקע למניעת הפרעות ויזואליות.

## 🚀 איך מתקינים?

1. ודאו שיש לכם את תוסף הדפדפן **Tampermonkey** מותקן.
2. לחצו על הקישור הבא להתקנה מהירה:
   [לחצו כאן להתקנת הסקריפט](https://github.com/HAKOL-MILEMALA/aliexpress-fast-load/raw/refs/heads/main/aliexpress-fast-load.user.js)
3. בחלון שייפתח, לחצו על **Install** (התקנה).

## 🔄 עדכונים אוטומטיים
הסקריפט כולל מנגנון עדכון מובנה ויתעדכן עצמאית בכל פעם שיעלה שיפור או תיקון קוד למאגר זה.
