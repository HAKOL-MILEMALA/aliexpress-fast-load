# אליאקספרס - כפתור טעינה מהירה (Tampermonkey)

סקריפט המשפר את ממשק השותפים (Affiliate) באתר AliExpress. הסקריפט מוסיף כפתור "⚡ טען" ייעודי לצד הכפתור המקורי, שמייצר את קישור ההפניה ומעביר אליו אוטומטית ובמהירות, תוך הסתרת החלון הקופץ ברקע למניעת הפרעות ויזואליות.

## 🚀 איך מתקינים?

1. ודאו שיש לכם את תוסף הדפדפן **Tampermonkey** מותקן.
2. לחצו על הקישור הבא להתקנה מהירה:
   [לחצו כאן להתקנת הסקריפט](https://github.com/HAKOL-MILEMALA/aliexpress-fast-load/raw/refs/heads/main/aliexpress-fast-load.user.js)
3. בחלון שייפתח, לחצו על **Install** (התקנה).

## 🔄 עדכונים אוטומטיים
הסקריפט כולל מנגנון עדכון מובנה ויתעדכן עצמאית בכל פעם שיעלה שיפור או תיקון קוד למאגר זה.

---

## 🛍️ בדיקת "חוסכים בגדול" ב-AliExpress

סקריפט Tampermonkey שבודק אם המוצר שבו צופים מופיע ראשון בתוצאות הרגילות של **חוסכים בגדול** ב-AliExpress.

### ✨ מה הסקריפט עושה?

- בודק אם המוצר הנוכחי הוא המוצר הראשון בתוצאות הרגילות, תוך התעלמות מכרטיסים מקודמים.
- מציג את מחיר המוצר כאשר ניתן לזהות אותו.
- כאשר המוצר נמצא, מציג קישור ירוק לפתיחת עמוד "חוסכים בגדול". אפשר גם ללחוץ עליו בקליק ימני ולהעתיק את הקישור.
- כאשר המוצר לא נמצא או שלא ניתן להשלים את הבדיקה, מוצג סטטוס מתאים.
- מתאים את המיקום, הרוחב והעיצוב של הקישור לכפתורי הקנייה המקוריים של AliExpress.

### 📥 התקנה

1. מתקינים את [Tampermonkey](https://www.tampermonkey.net/) — בוחרים באתר את הדפדפן שבו משתמשים ומתקינים את התוסף.
2. לוחצים על הקישור להתקנה ישירה:

   👉 **[לחצו כאן להתקנת הסקריפט](https://raw.githubusercontent.com/HAKOL-MILEMALA/aliexpress-fast-load/main/aliexpress-bundle-deals-check.user.js)**

3. בחלון שייפתח ב-Tampermonkey לוחצים על **Install** (התקנה).
4. זהו! הסקריפט יפעל בעמודי מוצרים של AliExpress ויתעדכן אוטומטית כאשר תפורסם גרסה חדשה במאגר.

### ℹ️ מידע נוסף

- הסקריפט מופעל בעמודי מוצר של AliExpress בלבד.
- לצורך הבדיקה הוא שולח בקשה לעמוד Bundle Deals של AliExpress דרך הרשאת Tampermonkey.
- אין צורך להזין פרטים אישיים או להירשם לשירות נוסף.
- במקרה של שינוי במבנה האתר, ייתכן שיהיה צורך לעדכן את הסקריפט.
